# Python Basic Programs 🐍

This repository contains simple Python programs for beginners to practice basic programming concepts such as input, conditions, calculations, and string operations.

## 📚 Programs Included

| Program          | Description                                                     |
| ---------------- | --------------------------------------------------------------- |
| `hello.py`       | Basic Python program to print a message                         |
| `profit_loss.py` | Calculates profit or loss based on cost price and selling price |
| `even_odd.py`    | Checks whether a number is even or odd                          |
| `voting.py`      | Checks whether a person is eligible for voting based on age     |
| `anagram.py`     | Checks whether two words are anagrams                           |

## 🛠️ Technologies Used

* Python 3
* VS Code
* Git & GitHub

## ▶️ How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run any program using:

```bash
python filename.py
```

For example:

```bash
python even_odd.py
```
